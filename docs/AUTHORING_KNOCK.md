# 100本ノック（フォローアップクエスチョン生成）作問ガイド

対象: `data/questions_knock_v1.json`（マスター）→ `app/data/` へコピーして同梱。
型の定義と線引きは [followup/FOLLOWUP_PATTERNS.md](followup/FOLLOWUP_PATTERNS.md) を正とする。

## 練習の狙い

質問ドリル（`questions_followup_v1.json`）が「質問文 → 型を当てる」分類練習なのに対し、
ノックは「相手の回答文 + 指定の型 → 自分で質問を作る」生成練習。
**フラッシュカード形式**: 質問は入力せず頭の中（できれば声に出して）で作り、「答えを見る」で模範解答（一例）を
開いて自己採点する（◎型どおりの質問が自然に出た / ○型は合うが硬い・迷った / ×別の型になった・出てこなかった）。
自動採点はない。

## 8つの型

PATTERNS.md の7分類のうち、①詳細を「具体化」「背景」に分けて8型とする。キーは以下。

| キー | 型 | アンカー |
|---|---|---|
| `1a` | 詳細（具体化） | 具体的には、どういうことですか？ |
| `1b` | 詳細（背景） | きっかけは何だったんですか？ |
| `2` | 感想・意見 | 〜については、どう思ってますか？ |
| `3` | 理由・目的 | それを選んだ決め手は何だったんですか？ |
| `4` | 結果・影響 | それで、どうなったんですか？ |
| `5` | 対策・次の一手 | 次は、どうするんですか？ |
| `6` | 比較・対比 | 他のと比べて、どうなんですか？ |
| `7` | 振り返り | 今振り返ってみて、どうですか？ |

## 形式

```json
{
  "version": 1,
  "topics": { "a": "最近ハマっていること", "b": "…", "c": "…", "d": "…", "e": "…" },
  "personas": { "p01": { "name": "田中 美咲", "profile": "28歳・Webデザイナー・都内で一人暮らし" }, "…": {} },
  "items": [
    {
      "id": "kn_a01",
      "topic": "a",
      "persona": "p01",
      "answer": "最近はサウナにハマってますね。…（3〜4行）",
      "questions": {
        "1a": { "phrase": "「ととのう」って、具体的にはどういう感覚なんですか？", "why": "相手が使った曖昧語をそのまま拾って明確化" },
        "1b": { "phrase": "…", "why": "…" },
        "2": {}, "3": {}, "4": {}, "5": {}, "6": {}, "7": {}
      }
    }
  ]
}
```

- `id` は `kn_{話題}{ペルソナ番号}`（例: 話題 a × p07 → `kn_a07`）
- 話題は5つ固定: (a) 最近ハマっていること (b) 最近びっくりしたこと (c) 子どもの頃ハマっていたこと
  (d) 今までで一番自慢したいこと (e) 今までで一番失敗したこと
- ペルソナ10人は全話題に回答する（10×5=50本）。年齢・職業・生活環境を散らす
- `answer` は3〜4行（100〜170字目安）の話し言葉。**8型すべての質問が自然に成立する材料**を入れる:
  曖昧語（具体化）、始まりの経緯（背景）、評価できる対象（意見）、選択・こだわり（理由）、
  その後の展開（結果）、これから（次の一手）、対比できる相手（比較）、過去（振り返り）
- `questions` は8型すべて必須。`phrase` は実際に口にできる一文、`why` はその型である根拠・引き出したいもの（短く）
- アプリ側は `app/js/knock.js` の `expandKnock` で (回答文×型) の仮想問題（id `kn_a01_1a` 等、`kind: "knock"`）に展開する。
  記録・復習・成績はこの仮想 id 単位

## 品質基準

1. **型の一意性**: 模範質問は指定の型に読めること。特に 背景(1b)↔理由(3)、結果(4)↔次の一手(5)、
   意見(2)↔振り返り(7) の境界を PATTERNS.md の線引きどおりに守る
   - 背景: 過去の経緯・事実（いつ・どうやって・きっかけ）／ 理由: 今の動機・価値（なぜ・決め手・何のため）
   - 結果: すでに起きたことの続き ／ 次の一手: まだ起きていないこと
   - 意見: 対象への評価 ／ 振り返り: 自分の過去の再解釈
2. **自然さ**: 相手の言葉（「ととのう」「散々」など）を拾う。尋問調・書き言葉は不可
3. **回答文への密着**: 回答文に根拠のないことを前提にした質問を作らない
4. **既出のことを聞かない**（ユーザー指摘 2026-08-29）: 回答文に既に書かれている情報を尋ねる質問は不可
   （例: 「海の上にいると仕事を忘れられる」と言っている相手に「釣りの何がいいんですか？」／
   「それ以来3回訪問するようにしてます」と言っている相手に「前と後で何が変わりました？」）。
   回答文の言葉は拾ってよいが、聞くのは**その先**（中身・経緯・周りの反応・次など、まだ語られていないこと）
5. **模範は一例**: 自己採点では「型に合っているか」「自然か」で見る。模範と一致する必要はない

## 出題の仕組み

- 1セッション = 100問（既定）。50回答文を1周ずつ回し、各周で回答文ごとにランダムな型を1つ選ぶ
  → 各回答文が2型ずつ、同じ回答文は連続しにくい。未回答の (回答文, 型) を優先
- 「10本だけ」は同じ仕組みで10問
