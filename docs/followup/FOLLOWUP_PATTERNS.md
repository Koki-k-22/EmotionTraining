# フォローアップクエスチョン 7つの型

## 目的

フォローアップクエスチョンの目的は、**相手の話を決めつけずに、真意が分かるまで質問を続けること**。
質問で相手の感情や状況の背景を正確に理解したうえで、最後に

- **言い直し**（「つまり〜ということなんですね」）
- **感情の言語化**（「それは悔しかったですね」「プライドが傷ついたんですね」）

で返すことがゴール。質問は情報収集の手段であり、着地点は Active Listening（言語化して返す）にある。

覚えるのは **7つの型の名前と、各型のアンカーフレーズ（太字）**。残りの定型文はバリエーションとして眺めておけば、型さえ想起できれば口から出るようになる。

## 7つの型と定型文

### ① 詳細を尋ねる

**(a) 具体化** — 曖昧な部分を明確にする

- **「具体的には、どういうことですか？」**
- 「もう少し詳しく教えてもらえますか？」
- 「例えば、どんな感じなんですか？」
- 「それって、どういう意味ですか？」
- 「一番印象に残ってるのは、何ですか？」
- 「特にどのあたりが？」

**(b) 背景** — 経緯・きっかけ・やり方を引き出す。自分が詳しくない分野や共通点が少ない相手でも話を広げやすい

- **「きっかけは何だったんですか？」**
- 「なんでそれにハマったんですか？」
- 「どうやって時間を作ってるんですか？」
- 「いつから始めたんですか？」
- 「どこでそれを知ったんですか？」
- 「どうやって身につけたんですか？」
- 「最初からうまくいったんですか？」

### ② 感想や意見を求める

- **「〜については、どう思ってますか？」**
- 「正直なところ、どう感じてます？」
- 「〜さん的には、それってアリなんですか？」
- 「実際にやってみて、どうでした？」
- 「率直な感想を聞きたいです」
- 「〜さんの目から見て、どうなんですか？」
- 「期待どおりでした？」

### ③ 理由や目的を尋ねる

- **「それを選んだ決め手は何だったんですか？」**
- 「一番の狙いは何なんですか？」
- 「何がそんなに良いんですか？」
- 「何のためにやってるんですか？」
- 「どうしてそう思ったんですか？」
- 「何かこだわりがあるんですか？」

### ④ 結果や影響を尋ねる

相槌のように、相手の話の先を促す

- **「それで、どうなったんですか？」**
- 「それでそれで？」
- 「周りの反応はどうでした？」
- 「結局、うまくいったんですか？」
- 「何か変化はありました？」
- 「相手は何て言ったんですか？」

### ⑤ 対策や次のステップを尋ねる

- **「次は、どうするんですか？」**
- 「この後の予定はあるんですか？」
- 「他にもやってみたいこと、あります？」
- 「次の目標って何ですか？」
- 「これからどうしていくつもりですか？」
- 「何か対策は考えてるんですか？」

### ⑥ 比較や対比を求める

- **「他のと比べて、どうなんですか？」**
- 「今と昔で、何が違いますか？」
- 「他の人は、どうしてるんですか？」
- 「前と比べて、変わりました？」
- 「〇〇とは、どう違うんですか？」
- 「他の選択肢も考えたんですか？」

### ⑦ 振り返りを促す

- **「今振り返ってみて、どうですか？」**
- 「その時の自分にアドバイスするとしたら、何かあります？」
- 「もう一度やり直せるなら、何を変えます？」
- 「あの経験って、今に活きてます？」
- 「一番の転機は、いつでした？」
- 「やってきて一番良かったことは、何ですか？」

## 締めの一手 — 言語化で着地する（8つ目の型ではなく、ゴール）

質問を2〜3回重ねて仮説が固まったら、質問ではなくこれで返す。

- 言い直し: 「つまり、〜ということなんですね」
- 感情の言語化: 「それは〜だったんじゃないですか」「〜な気持ちになりますよね」
- 確認: 「〜という理解で合ってます？」

ズレていたら相手が訂正してくれるので、また質問に戻ればよい。仮説は押しつけず、**訂正の余地を残した差し出し方**をするのがコツ。

## 紛らわしい境界の線引き（分類ドリル用）

- **詳細①(背景) vs 理由③**: 過去の経緯・事実（いつ・どうやって・きっかけ）を聞くなら**詳細（背景）**。今の動機・価値（何のため・何がいい）を聞くなら**理由**。「なぜハマったの？」は文脈次第でどちらにもなる。
- **結果④ vs 次の一手⑤**: すでに起きたことの続きなら**結果**、まだ起きていないことなら**次の一手**。
- **意見② vs 振り返り⑦**: 対象への評価を聞くなら**意見**、自分の過去の再解釈を聞くなら**振り返り**。
